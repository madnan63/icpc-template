# ICPC Python Reference

This repository contains only the algorithms and formulas currently used in my ICPC template. Compile the template.tex in overleaf or any other .tex compiler to generate the pdf. A version of the latest pdf can be found in releases.

## Layout

- `code/01_python` — Python syntax and fast I/O
- `code/02_binary_search` — binary search on answer
- `code/03_number_theory` — prime/factorization/combinatorics utilities
- `code/04_geometry` — polygon area
- `code/05_graph` — DFS, tree traversals, Dijkstra, topo sort, DSU
- `code/06_data_structures` — Fenwick and segment tree
- `notes` — formulas and short reference material
